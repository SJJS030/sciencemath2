# 🌏 지진 진원지 찾기 — 지구과학×수학 융합 수업

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 활동 단계

1. **상황 파악** — 2016년 경주 지진 발생 정보와 세 관측소(대구·울산·포항) 위치 확인
2. **위치 표시** — 좌표평면에 세 관측소 위치를 버튼으로 표시, 마우스 호버로 PS시·진원거리 확인
3. **진원거리 입력** — PS시 데이터를 참고해 각 관측소의 진원거리를 입력
4. **원의 방정식** — 각 관측소를 중심, 진원거리를 반지름으로 하는 원의 방정식 입력 후 시각화
5. **현과 진원** — 세 원의 교점을 이은 현을 그리고 세 현의 교점(진원)을 확인
6. **결과 확인** — 학생 추정 진원과 실제 진원 위치 비교

## 수학 개념
- 원의 방정식: (x-a)²+(y-b)²=r²
- 두 원의 공통현
- 현의 교점으로 원의 중심(진원) 역추적

## 과학 개념
- P파, S파, PS시
- 진원거리 공식: D = PS시 × Vp×Vs/(Vp-Vs)
